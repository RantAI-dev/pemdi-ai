## Kenapa

Pesan galat ditentukan di tempat kejadian, dari teks bebas, dan satu tempat membocorkan teks
internal:

- `src/app/error.tsx:29` mencetak `error.message` mentah ke pengguna. Untuk galat server itu berarti
  teks exception, dan tidak ada cara menghubungkannya ke log.
- `src/lib/api.ts:5` mengirim `e.message` apa adanya untuk 500, lalu UI menampilkannya
  (`dokumen.tsx:33`, `penilaian.tsx:26`, `login/page.tsx:19`).
- Tidak ada satu tempat yang memetakan kode ke kalimat. `docs/conventions.md` menetapkan pesan
  registry dalam bahasa Inggris dan UI memilih teksnya sendiri menurut `code` — itu belum ada.
- Status yang muncul hari ini tidak konsisten dengan tabel konvensi: 422 di
  `src/app/api/penilaian/ai/route.ts:14` (konvensi: 400), 503 tanpa `Retry-After` di
  `src/app/api/dokumen/route.ts:28`.

## Yang didapat pengguna

Setiap kegagalan berbunyi dalam bahasa Indonesia, menyebut apa yang bisa dilakukan, dan membawa
nomor rujukan (`requestId`) yang bisa disebutkan ke pengelola — tanpa pernah menampilkan teks
sistem.

## Rancangan

### `src/components/galat.ts` — satu peta, murni

```ts
import type { ErrorCode } from "@/contracts/api-error";

export const PESAN: Record<ErrorCode, { judul: string; pesan: string }>;
export function pesanGalat(code: ErrorCode | undefined, status?: number): { judul: string; pesan: string };
export function rujukan(requestId: string | undefined): string | null; // "Rujukan: <id>" atau null
```

Isi pesan (bahasa Indonesia, satu kalimat, tanpa istilah teknis):

| Code | Judul | Pesan |
| --- | --- | --- |
| `invalid_request` | Permintaan tidak valid | Periksa kembali isian yang dikirim. |
| `unauthenticated` | Belum masuk | Masuk kembali untuk melanjutkan. |
| `permission_denied` | Tidak diizinkan | Akun ini tidak punya akses ke bagian tersebut. |
| `not_found` | Tidak ditemukan | Data yang dicari tidak ada atau sudah dipindahkan. |
| `conflict` | Bentrok dengan data lain | Muat ulang halaman, lalu ulangi. |
| `payload_too_large` | Berkas terlalu besar | Perkecil berkasnya, lalu unggah lagi. |
| `unsupported_media_type` | Jenis berkas tidak didukung | Pakai PDF, DOCX, XLSX, atau gambar. |
| `rate_limited` | Terlalu banyak permintaan | Tunggu sebentar, lalu coba lagi. |
| `internal` | Ada gangguan di sisi kami | Coba lagi; bila berulang, sampaikan nomor rujukan di bawah. |
| `upstream_failed` | Layanan terkait sedang bermasalah | Coba lagi beberapa saat lagi. |
| `unavailable` | Layanan sedang tidak tersedia | Coba lagi beberapa saat lagi. |
| `timeout` | Permintaan terlalu lama | Coba lagi; bila sering terjadi, perkecil rentang datanya. |

`pesanGalat` menerima `code` yang tidak dikenal (route lama tidak mengirim `code`) dan memilih
menurut `status`: 401 → `unauthenticated`, 404 → `not_found`, 429 → `rate_limited`, 502 →
`upstream_failed`, 503 → `unavailable`, 504 → `timeout`, 400–499 → `invalid_request`, selain itu
`internal`. Tidak pernah memakai teks dari server.

### Pemakaian

- `src/app/error.tsx`: hapus `<p …>{error.message}</p>` di baris 29. Ganti dengan `pesanGalat(undefined)`
  dan, bila ada, `rujukan(error.digest)`. Teks "Aplikasi baru saja diperbarui" untuk `ChunkLoadError`
  tetap (`error.tsx:12`).
- `src/app/{dokumen,penilaian,kebutuhan,opd,data}/**`, `src/app/tanya/tanya.tsx`,
  `src/app/login/page.tsx`, `src/components/makro-halaman.tsx`: setiap `catch` menampilkan
  `pesanGalat(err instanceof ApiError ? err.code : undefined, err.status)` + `rujukan(err.requestId)`.
  Jangan menampilkan `err.message`.
- `src/app/api/penilaian/ai/route.ts:14`: **jangan** diubah — bentuk route dibekukan sampai cutover
  (`PORT-48`). Catat di badan PR sebagai selisih yang diketahui; `FE-5d` yang menanganinya.
- `src/app/api/dokumen/route.ts:28`: idem, `Retry-After` ditambahkan di `PORT-42`.

### Test

`src/components/galat.test.ts`:

1. Setiap `ErrorCode` punya `judul` dan `pesan` tidak kosong, dan pesannya tidak sama dengan teks
   registry Inggris (mis. bukan `"Something went wrong on our side."`).
2. `pesanGalat(undefined, 503).judul === "Layanan sedang tidak tersedia"`.
3. `pesanGalat("invalid_request")` tidak memuat kata "invalid" atau "request".
4. `pesanGalat("code_yang_tidak_ada" as ErrorCode, 500)` → `internal`, tidak melempar.
5. `rujukan("0193…")` → `"Rujukan: 0193…"`; `rujukan(undefined)` → `null`.
